# Changelog

All three plugins share one version. Bump it in each `plugins/<name>/plugin.json` **and** in `.github/plugin/marketplace.json` so VS Code and Copilot CLI detect the update.

## 1.1.0 — 2026-09-29

### ✨ VS Code
- Hooks now work in VS Code (Copilot and Local session targets). VS Code runs plugin hooks itself and doesn't provide `${PLUGIN_ROOT}` for Agent Plugins 1.0 packages. Each hook is now a plain `node -e 0 <plugin> <script>` command with a small bootstrap in `env.NODE_OPTIONS` that finds the installed plugin. The hooks are generated by `tools/build-hooks.mjs` and work in bash, PowerShell and cmd.exe.
- Added automation templates (**Templates from Plugins** in the Agents window). They live in `com.github.copilot/automations/` and are registered through `extensions.com.github.copilot.automations` in `plugin.json`.
- Custom agents gained `argument-hint`, and **security-reviewer** and **release-captain** gained VS Code `handoffs`.
- Added workspace plugin recommendations in `.github/copilot/settings.json`.
- `sessionStart` hooks no longer assume the process working directory is the workspace. VS Code doesn't pass one, so the repo-aware hooks skip instead of scanning `/`.

### 🛡️ Secure Code Guardian
- The guardrail handles batched `toolCalls` payloads.
- It blocks `--force-with-lease` pushes to `main`/`master`/`release/*`.
- It catches `rm` aliases, nested shells and PowerShell/cmd recursive deletes.
- Detection of secret files is token-aware, which cuts false positives and adds coverage for globs, redirects and Windows paths.

### 🚢 Ship-Ready
- Git refs passed to `changelog_from_git` are validated to block option injection.

### 🧪 Tooling
- The validator now checks automation templates (same rules as VS Code), generated hooks, workspace recommendations, and version consistency across skills and MCP servers.
- Every hook command is tested the way each client runs it: expanded `${PLUGIN_ROOT}`, the VS Code install layouts, and plugin not installed.

## 1.0.0 — 2026-09-28

- First release: **ship-ready**, **secure-code-guardian** and **docs-onboarding-buddy**, each with a skill, custom agent, hooks and MCP server.
